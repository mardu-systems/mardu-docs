Diese Dokumentation beschreibt das Webinterface von Mardu v1 in der Reihenfolge
des Arbeitsalltags: Grundlagen, tägliche Aufgaben, Verwaltung, Technik.
**Bediener** arbeiten mit Buchungen, Zutritt und Geräten; die
**Administration** verwaltet Benutzer, Rollen, Zutritt, Geräte und Server.
