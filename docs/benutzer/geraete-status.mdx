## Anzeigen einordnen

| Beobachtung                         | Bedeutung                                                               |
| ----------------------------------- | ----------------------------------------------------------------------- |
| Ressource im Katalog sichtbar       | Du darfst das Angebot sehen; weitere Nutzungsbedingungen können gelten. |
| Freigabe innerhalb ihrer Zeiten     | Die zeitliche Bedingung ist erfüllt.                                    |
| Buchung bestätigt                   | Die Reservierung ist bestätigt.                                         |
| Gerät offline oder Meldung veraltet | Der aktuelle physische Zustand ist nicht bestätigt.                     |
| Abfrage fehlgeschlagen              | Der aktuelle Zustand ist unbekannt.                                     |

Eine Portal-Anzeige bestätigt keine geöffnete Tür oder freigeschaltete Maschine.
Dafür sind Rückmeldungen der Hardware erforderlich.

## Eine Störung eingrenzen

1. Prüfe Konto und Projekt.
2. Prüfe Zeitraum, Freigaben und erforderliche Einweisungen.
3. Lade fehlgeschlagene Bereiche erneut.
4. Melde die Störung an die zuständige Stelle deines Standorts.

Nenne Ressource, Zeitpunkt mit Zeitzone, sichtbare Meldung und deine Beobachtung
am Gerät. Teile keine Zugangsdaten oder persönlichen Kalenderlinks.

Diagnose und Updates gehören zur [Geräteverwaltung](../administration/geraete-verwalten.mdx),
Betriebsmetriken zu [Übersicht und Systemstatus](./uebersicht-monitoring.mdx).
