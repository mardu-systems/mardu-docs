Beginne mit dem Serveraufbau, wenn du eine neue Installation einrichtest. Bei
einem bereits laufenden Server kannst du direkt zur Geräteaufnahme im Dashboard
wechseln.

<span id="in-diesem-bereich" />

## Server aufbauen

[Server auf dem Raspberry Pi installieren](./raspberry-pi.mdx) beschreibt
Voraussetzungen, Installationspaket, Konfiguration, Start und Erstzugang. Prüfe
vorher die dort genannten Voraussetzungen und Zugänge zu den Images.

## Einen vorhandenen Server verwenden

Die [Geräteverwaltung in Administration](../administration/geraete-verwalten.mdx)
beschreibt die Aufnahme im Dashboard und die Zuordnung technischer Anschlüsse.
Die [Ressourceneinrichtung](../koordination/ressourcen.mdx) verbindet diese
Anschlüsse mit dem jeweiligen Raum, Werkzeug oder der Maschine.

## Zum Betrieb übergehen

- [Administration](../administration/index.mdx): Konten, Ressourcen und technische Funktionen einrichten.
- [Übersicht und Systemstatus](../benutzer/uebersicht-monitoring.mdx): gemeldete Zustände und fehlende Messwerte einordnen.
- [Mardu per CLI warten](../administration/wartungs-cli.mdx): lokale Diagnose und Kontowiederherstellung.

<span id="offene-dokumentationsaufgaben" />

Gerätespezifische Montage, physische Abnahme und eine vollständige
Übergabecheckliste sind noch nicht ausgearbeitet. Die Softwareaufnahme ersetzt
keine Anschluss- und Funktionsprüfung vor Ort.
