## Konventionen für neue Seiten

- Eine Datei pro Thema unter `content/docs/v2/`, z. B. `erste-schritte.mdx`.
- Jede Datei braucht `title` und `description` im Frontmatter.
- Neue Seite danach in `content/docs/v2/meta.json` unter `pages` eintragen.
- Interne Links relativ oder absolut auf `/docs/v2/...` setzen.
