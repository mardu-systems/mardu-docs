Dieser Bereich richtet sich an Personen, die eigene Software mit Mardu verbinden.
Der [Überblick](../ueberblick/index.mdx) erklärt zuerst das Modell aus Personen,
Ressourcen und optionalen technischen Funktionen.

<span id="in-diesem-bereich" />

## Eine Schnittstelle wählen

| Ziel                                                      | Einstieg                                                                                                  |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Einen Agenten oder MCP-Client verbinden                   | [MCP-Client anbinden](./mcp-anbindung.mdx)                                                                |
| HTTP-Endpunkte, Parameter und Antwortmodelle nachschlagen | **API** unter **Referenz** in der Seitenleiste öffnen. Die Referenz wird aus dem Backend-Vertrag erzeugt. |
| Den MCP-Zugriff für die Installation freigeben            | [MCP für Agenten freigeben → Administration](../administration/mcp-verwalten.mdx)                         |
| Die Automation-Runtime und den Editor vorbereiten         | [Automationen → Administration](../administration/automationen.mdx)                                       |

## Mit begrenztem Zugriff beginnen

Für eine persönliche MCP-Anbindung erstellst du einen eigenen Zugang. Die
[MCP-Anleitung](./mcp-anbindung.mdx) zeigt einen Leseaufruf und erklärt Tokenwechsel
und Fehler. Serverfreigabe, Tokenumfang und die aktuellen Rechte des Kontos
begrenzen den nutzbaren Zugriff gemeinsam.

<span id="offene-dokumentationsaufgaben" />

## Umfang der Anleitungen

Ausführliche Einstiege für HTTP-Clients, MQTT-Clients und eigene Automationsflüsse
sind noch nicht ausgearbeitet. Für Beiträge am Mardu-Quellcode gelten die
Entwicklungsanweisungen des jeweiligen Software-Repositories. Dieser Bereich ist
keine vollständige Anleitung zum Entwickeln des Servers oder Dashboards selbst.
